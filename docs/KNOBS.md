**These are defects unless a reason is attached.** A knob read in two
places with two different defaults is §0u — the same rule implemented
twice, implemented two different ways — and it is silent, because each
call site is correct on its own. `--check` fails on any entry here
that is not in `tools/knobs.py`'s `ACKNOWLEDGED`, and an entry there
costs a written justification.

## Before you trust a number

None of these can be derived from the filesystem, so they are printed as
commands rather than as answers:

```bash
python -m tools.validate        # must print +0.00 on all 18 metrics
python -m edhmc.pending         # staged changes, and deck legality
python -m tools.check_docs      # do the docs still match the repo?
python -m tools.audit_cards     # every card against Scryfall; expect 0 ERR
```

`tools/validate.py` is the non-negotiable one: anything other than
`+0.00` means randomness is leaking between the branches of every A/B
test in the project, and no number here can be trusted until it is fixed.
